# Schedule Management System (Система управління розкладом)

Програмний комплекс призначений для автоматизації процесів обліку, планування та посторінкового виведення розкладу навчальних занять (Лекцій, Практик та Іспитів).

## 🚀 Основний функціонал
- **Управління подіями:** Підтримка різних типів занять із використанням перелічуваних типів (`Enum`).
- **Персистентність даних:** Повне збереження та відновлення стану системи за допомогою бінарної серіалізації (`pickle`), читання конфігурацій з файлу `config.json` та експорт звітів у формат `CSV`.
- **Інтерактивний CLI-інтерфейс:** Текстове меню на базі оператора `match/case` з високим рівнем стійкості до некоректного введення даних користувачем (Fault Tolerance).
- **Фільтрація та пагінація:** Посторінкове виведення розкладу за допомогою генераторів та кастомний ітератор для фільтрації занять за номерами аудиторій.

## 🛠 Вимоги до середовища
- Python версії 3.10 або новішої.
- Інструмент збирання `setuptools` та менеджер пакунків `pip`.
